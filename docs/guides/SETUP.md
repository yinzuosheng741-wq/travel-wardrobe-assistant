# 服务配置

从首次启动向导，或“设置 → 服务状态 → 配置模型、天气与定位”打开设置。可以只配置需要的能力，也可以暂不配置，先使用离线衣橱。

## 模型

对话、图片识别和知识检索分别填写接口地址、API Key 与模型名称。兼容接口地址通常以 `/v1` 结尾；具体地址以服务商说明为准。

- 对话模型需要支持工具调用。
- 图片识别模型需要支持图片输入。
- 语义检索需要 Embedding 模型，不能填写对话模型名称；未配置时仍可使用本地 BM25 检索。

图片和向量页可复用对话的地址与密钥，但模型名称应分别填写。支持导入已有 `.env`。连接测试只检查本次基础响应，不保证全部业务正确。

## 天气与定位

- **高德**：填写自己的 Web 服务 Key 和默认城市。建议填写省份与城市，避免同名地区混淆。
- **Open-Meteo**：无需 Key；免费接口限非商业使用，存在限额和可用性限制，见[服务条款](https://open-meteo.com/en/pricing)。
- **关闭天气**：继续使用季节、场景和库存规则。

IP 城市定位默认关闭。主动开启后，仅在没有指定城市时请求高德推测城市；VPN 或网络出口可能影响结果，不等同于 GPS。

## 跨会话记忆

默认使用本地 SQLite，无需云记忆账号。设置中可关闭，在主窗口“设置 → 服务状态 → 查看与管理长期记忆”查看、删除或清空。

记忆在本机存储和检索；若使用远程对话模型，召回的少量记忆会作为本轮上下文发送给该模型。当前明确条件优先于历史记忆。删除过的相同内容不会因旧会话仍存在而自动恢复；新的不同偏好可再次记录。

## 配置与常见问题

配置保存在 `data/config/services.env`，密钥未加密。不要分享自己使用过的客户端目录，也不要把配置文件放入公开仓库。

- HTTP 401/403：检查密钥、额度与模型授权。
- HTTP 404：检查接口地址和模型名称。
- HTTP 429：检查额度与限流，稍后再试。
- 连接超时：检查代理、网络、证书及服务状态。
- 修改后保存即可应用；“已配置”仅表示已填写，实际连接请用设置页测试。

衣橱操作和备份方法见[客户端指南](DESKTOP.md)。

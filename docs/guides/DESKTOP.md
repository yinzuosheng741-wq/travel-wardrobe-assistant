# 出行衣橱助手 客户端指南

使用前可先阅读[服务配置](SETUP.md)。

客户端使用 PySide6 / Qt Widgets 原生界面，运行不依赖浏览器或 WebView。

## 启动与升级

从 [最新 Release](https://github.com/yinzuosheng741-wq/travel-wardrobe-assistant/releases/latest) 下载 Windows 便携 ZIP，解压后运行其中的 `出行衣橱助手.exe`。公开下载无需 GitHub 账号，版本附件不受 Actions 临时产物保留期限制。

源码环境安装 `requirements.txt` 后，运行 `python desktop.py`。双击 `Start.vbs` 隐藏控制台启动，`Start.cmd` 显示诊断输出。

独立分发目录为 `dist/native/出行衣橱助手/`，启动其中的 `出行衣橱助手.exe`。分发包包含 Python、Qt 和应用依赖，接收者无需安装 Python。移动时保留整个目录，放在可写位置。

源码运行继续使用原来的 `data/stylemate.db`、`data/uploads/` 和 `.env`；升级界面不迁移或清空用户数据。独立分发包默认从新衣橱开始。需要迁移时：

1. 退出旧客户端并备份整个 `data/` 目录。
2. 将完整的 `data/` 复制到新客户端目录。
3. 将已保存的 `data/config/` 和 `data/desktop/ui.ini` 一同迁移。旧 `.env` 可在首次启动向导导入，原文件无需删除。

首次启动会创建 128 件演示衣物；已有数据库不会被覆盖，用户已删除的样例不会在重启时恢复。

## 界面与操作

浅色侧栏包含“我的衣橱、今日搭配、衣橱助手、搭配收藏”，设置放在底部。

- **我的衣橱**：搜索名称、颜色、材质或风格；按类别、季节筛选，按时间或名称排序。每页 12 件，窗口宽度改变时自动排为 2–4 列。自定义类别与“四季”衣物也支持筛选。
- **添加衣物**：在右上角选择“上传照片识别”或“手动录入”。照片必须为有效 JPG/PNG/WEBP，最大 8 MB。识别后可编辑草稿，确认才保存。无视觉服务时仍可手动录入。
- **衣物详情**：查看大图与完整信息，编辑或删除；点击“咨询这件衣物”可在助手中询问这件衣物的搭配或洗护。删除需要二次确认，并清理关联照片。
- **今日搭配**：选择场景、季节、城市和排除条件。搭配仅使用真实库存，支持收藏与取消收藏；规则分数只用于候选排序。
- **衣橱助手**：连续对话、历史会话、洗护、旅行与购买建议，来源链接可打开。顶部“选择衣物”可搜索单品，选择按会话保留并可取消；指定搭配只返回包含该件衣物的库存组合，材质未知时先查看洗护标签。快捷问题先填入输入框，可编辑后再发送。衣橱写操作显示中文字段的修改前后内容，确认才执行。
- **对话管理**：导入或移除 PDF/TXT/Markdown 会话资料、导出当前对话、确认后清空会话。入口位于对话页面顶部。
- **设置**：分为“穿衣偏好、服务状态、数据与关于”三个页签。支持保存偏好、查看服务配置、打开数据目录、JSON 衣橱导出、完整备份及查看项目源码。

快捷键：`Ctrl+F` 搜索衣橱、`Ctrl+N` 新建对话、`Ctrl+Enter` 发送。草稿按会话自动保存，重启恢复上次会话；窗口位置也会恢复。界面状态保存在应用目录 `data/desktop/ui.ini`；衣橱数据备份不包含界面状态和服务密钥。

识别、搭配、对话和资料索引在后台运行。任务期间暂停业务操作，完成后恢复，以防重复提交或中断写入；失败时可重试，未发送草稿保留。

## 配置与备份

在“设置 → 服务状态 → 配置模型、天气与定位”中分别配置模型、视觉、Embedding 与天气服务，支持导入 `.env`、逐项测试连接、保存并即时应用。“服务状态”只表示配置情况；未配置时仍可使用手动衣橱、规则搭配和本地 BM25 检索。

在“设置 → 数据与关于 → 创建完整备份”生成 ZIP，包含 SQLite 在线快照、关联衣物照片、偏好、会话和资料，以及 SHA-256 文件清单。缺少关联图片时中止，不覆盖先前备份。密钥、日志、向量缓存与 Qt 界面状态不进入备份。

本地长期记忆：在服务配置的“跨会话记忆”页启用或关闭，无需 Mem0 或其他云账号。已确认偏好、当前对话表达的条件与场景会按来源记录，并通过本地关键词检索用于后续对话；照片和原始资料不会进入记忆检索。存储与检索不调用网络；若对话使用远程模型，召回的少量记忆会作为本轮上下文发送给该模型。当前明确条件优先，记忆不能充当工具授权或洗护证据。“设置 → 服务状态 → 查看与管理长期记忆”支持删除和清空；完整备份同时包含存在的 `data/memory/sync.sqlite3`。

恢复时退出客户端，另存当前 `data/` 后，将备份中的 `data/stylemate.db`、`data/uploads/` 和存在的 `data/memory/` 放回应用目录。密钥使用 `data/config/services.env` 中自己保存的配置。JSON 衣橱清单不包含照片与会话，不能代替完整备份。

## 自行打包

```powershell
.venv\Scripts\python.exe -m pip install pyinstaller==6.11.1
.venv\Scripts\python.exe scripts/build_desktop.py
```

输出目录为 `dist/native/出行衣橱助手/`，公开压缩包为 `dist/TravelWardrobeAssistant-Windows-Portable.zip`。请分享干净公开包，保留个人目录自用。源码 ZIP 不包含运行环境；完整便携 ZIP 包含 Python 和 Qt。
